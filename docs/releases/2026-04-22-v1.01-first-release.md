# 售前管理系统 v1.01 首发版本发布声明

发布日期：2026-04-22

版本标识：v1.01

内部构建版本：1.0.1

本次发布为售前管理系统首个正式发布版本，发布目标是形成可在新环境独立初始化、独立部署、独立验证的业务基线。

## 发布范围

1. 提供客户、项目、解决方案、工作台、消息中心、字典管理、预警能力等核心业务模块。
2. 提供统一的数据字典配置能力，并支持通过同步接口将系统预置字典写入数据库。
3. 提供面向新环境的基础初始化能力，避免首次部署后再手工逐项配置系统枚举。

## 初始化原则

1. 新环境默认仅初始化系统基础数据。
2. 客户、解决方案、项目信息、工作台信息、消息信息等业务数据不作为首发版本的默认交付内容。
3. 如确需演示数据，必须显式开启 `SEED_INCLUDE_BUSINESS_DATA=true` 后再执行初始化。

## 发布说明

1. 字典配置以仓库内系统配置为准，通过接口同步到数据库，作为新环境的标准初始字典集。
2. 首发版本重点保证“可部署、可初始化、可登录、可配置”，不携带历史业务痕迹。
3. 本版本可作为后续补丁和迭代发布的稳定基线。
